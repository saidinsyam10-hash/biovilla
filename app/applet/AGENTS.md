# Rules and Preferences for the Project

## Isolated Feature Modifications (Strict Scope)
- **Zero Unintended Side Effects**: When the user requests a change or refinement to a specific feature, screen, or element (e.g. stage 0 Petunjuk, quiz question, hotspot, or styling), **DO NOT** modify, refactor, or alter any other features, stages, data structures, or components.
- **Preserve Existing State & Assets**: Keep all existing working features, audio mappings, question sets, graphics, and layout coordinates completely intact unless the user explicitly requests changes to them.
